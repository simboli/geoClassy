# Legacy documentation (0.1.x)

These files document the **0.1.x function API** — `loadFile`, `getNames`,
`numPoly`, `checkPoly`, `polyList` — which is deprecated since 0.2.0 and will be
removed in 1.0. They are kept for anyone maintaining older code.

Be aware that they describe behaviour that was wrong. The worked example in
`geoClassy_documentation.md` places the New York Public Library in *Chelsea*: a
consequence of the overlap bug fixed in 0.2.0, where the answer was whichever
matching area happened to come last in the file.

For current usage, see the [README](../../README.md).
